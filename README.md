# AgentsOfMine for VS Code — retired

> **This extension has been retired and the repository is archived.** It was never published to the VS Code Marketplace or Open VSX.

The [AgentsOfMine collector](https://github.com/AgentsOfMine/collector) is the only client. It works the same in any terminal or editor, including the VS Code integrated terminal.

```sh
npx agentsofmine pair     # one-time: prints a URL + QR, approve it on your phone
aom start                 # background sync
aom status                # paired? last synced when?
```

See the collector README for install and usage: <https://github.com/AgentsOfMine/collector#readme>
