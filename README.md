# vscode-agentsofmine

The official [AgentsOfMine](https://agentsofmine.io) extension for Visual Studio Code.

AgentsOfMine turns your AI coding agent sessions — Claude Code, OpenCode, Codex — into a searchable development memory you can revisit on mobile.

This extension is the local collector. It reads conversations your agents already wrote to disk, normalizes them on your machine, and syncs them to your AgentsOfMine account. It is **read-only by design**: it never controls your agents, never sends prompts, and never signs into your AI provider accounts.

## Status

Pre-release. Not yet on the VS Code Marketplace.

## Privacy

- Local-first collection
- You choose which projects sync
- Encrypted in transit, encrypted at rest
- Export anytime, delete anytime
