# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest `main` | ✅ |
| older releases | ❌ |

## Reporting a vulnerability

**Do not file a public GitHub issue for security vulnerabilities.**

Email **security@agentsofmine.io** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

You will receive an acknowledgement within 48 hours and a status update
within 7 days. We will coordinate a fix and a responsible disclosure
timeline with you before anything is made public.

## Scope

This policy covers the `vscode-agentsofmine` VS Code extension and its
interaction with the AgentsOfMine backend API. It does not cover
third-party dependencies — please report those to their respective
maintainers.
